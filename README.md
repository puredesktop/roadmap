# PureDesktop roadmaps

A text mirror of the `roadmap`-labelled GitHub issues for the 17 PureDesktop apps, exported on 2 October 2026. Each app has its own folder; each issue has one Markdown file. Original issue descriptions, numbering, contribution metadata and implementation-brief links are preserved.

The linked GitHub issues are the source of truth. This repository is a snapshot; subsequent issue edits are not copied automatically.
